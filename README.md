# Redwan Ansary — Portfolio

A modern, responsive personal portfolio built with plain HTML, CSS and JavaScript.

> Theme: **Obsidian & Gold** — an editorial dark palette with warm gold accents, serif display typography, subtle motion, and a focus on readability and craft.

## Live demo

https://ansary00.github.io/Portfolio_01/

## What's inside

- **Hero** — introduction, animated role rotator, stats and profile portrait
- **About** — a short story plus an "at a glance" panel
- **Education** — BSc in Computer Science & Engineering, Varendra University
- **Skills** — HTML, CSS, C++, Python, Networking and Problem Solving
- **Projects** — Student Management System, VLAN Network Design, Student Marketplace
- **Photography** — responsive gallery with a keyboard-accessible lightbox
- **Contact** — contact details and a form that opens a ready-to-send email draft

## Features

- Fully responsive (mobile → desktop)
- Accessible semantics, skip link, focus states and ARIA labels
- Scroll-reveal animations with `prefers-reduced-motion` support
- Active navigation highlighting and sticky glass header
- No frameworks or build step — just open `index.html`

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure and content |
| `styles.css` | Theme, layout, responsive styles and animations |
| `script.js` | Menu, reveals, lightbox, counters and contact form |
| `README.md` | This file |

Photographs are loaded from the original portfolio repository so this repo stays lightweight.

## Customise

Update the copy, project links and contact details in `index.html`. Colours and typography live in the `:root` block at the top of `styles.css`.
